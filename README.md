# BSCS26028_ProductWebsite
This website is a small online catalog for tech gadgets.
It has three pages:
1- home page introducing the store
2- products page showing gadgets and prices.
3-contact page with contact details and social links.

Visitors can use the navigation links to move between pages. On the products page, the “Check Availability” buttons provide product availability feedback through the site’s JavaScript. The contact page also includes a form for entering a name and email.
